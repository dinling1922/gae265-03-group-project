## 修了哪些規則

### 程式（rules.py、dates.py）

每個條件除了 `pattern` 之外，可以加：
- `exclude`：這一行同時符合就不算。
- `date`：`after`（欄名後面要讀得出日期）或 `line`（這一行要讀得出日期），用 `dates.dates_in()` 判斷，和保險期間檢查同一套解析。
- `next_line`：欄名自己一行時，下一行要符合這個樣式（表格版面）。

`dates.py`：四位數而且 0 開頭的不算年份。收據號碼 R-26-07-0153 原本會被讀成民國 153 年（2064-07-26）。

### D01 延誤期間

| | 前 | 後 |
|---|---|---|
| 時間 | 任兩行有「時:分」 | 原定（原定／原訂／預定／scheduled／STD／定刻／出発予定）＋時間，**加上**實際（實際／actual／ATD／実際）＋時間 |
| 時數 | `(延誤\|延遲\|delay).*數字(小時\|hours)` | 延誤字眼後面**緊接**數字與單位；加上遅延、時間、分鐘、minutes；排除「內／以內／within」 |
| 取消 | 「取消\|cancel」＋一個時間 | 「班機／航班／flight …取消／cancelled」或「欠航」＋一個時間 |

### D13 病名
- 欄名加上「傷病名」「診断名」；冒號後面要有兩個中日泰文字，或三個英文字母。
- 排除 see attached、見附件、別紙、待ち、待定、待查、待檢、pending、未定、N/A。
- 欄名單獨一行時，看下一行。

### D13 就診日期
- 欄名加上「受診年月日」「診察日」；排除次回、下次、下回、next、予約、預約、回診。
- 欄名後面不能是空白欄（底線、橫線）或冒號，而且要有數字。讀不出日期仍算有寫（既有決定，見下）。
- 句子寫法（examined／treated／seen／visited）：後面要讀得出日期。

### D14 金額
- 關鍵字加上請求額、お支払額、支払額、領収額；關鍵字後面緊接金額；數字後面不能接項、件、頁、items、年、月。
- 幣別加上全形 ￥、JPY、日圓。

### D14 日期
- 改成「這一行用 `dates.dates_in()` 讀得出日期」，和保險期間檢查一致，令和、「July 8, 2026」都認得。
- 排除出生、生年月日、birth、DOB、日生、歳。
