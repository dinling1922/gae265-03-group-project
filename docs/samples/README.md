# 範例檔案

專題用到的理賠範例文件，集中放在這裡，demo 或測試時直接拿來上傳。資料夾結構與 Google Drive 的「6號範例文件」相同。

> 這個 repo 是公開的。之後要加任何真實文件，請先遮蔽姓名、身分證字號、生日、地址、保單號碼與條碼。

## 範例文件（`範例文件/`）

6 號 agent（理賠文件辨識）demo 用的假文件，內容都是虛構的。除了兩份延誤證明，其他檔案與 `backend/app/agents/document/samples/` 的同名用途檔案內容相同，只是改成中文檔名、照 demo 情境分資料夾。

| 資料夾 | 用途 |
| --- | --- |
| `1_日本行程demo（安達進階型）/` | 主 demo：安達進階型保單，A 班機延誤、B 腸胃炎就醫、C 整趟共用文件 |
| `2_其他可通過的文件/` | 其他會通過檢查的寫法（富邦手寫申請書、搭機證明、身分證代替護照等） |
| `3_測試用_會被擋下或要確認的文件/` | 缺欄位、不在保險期間、不是理賠文件、照片模糊或反光、PDF 有密碼（密碼 0710） |

Drive 上的「9_舊版_可刪除」沒有放進來。
