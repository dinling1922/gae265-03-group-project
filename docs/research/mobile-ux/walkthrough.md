# 手機版實機走查（旅途中出事）

2026-11-12 起。目的：找出 Playwright 模擬 390px 抓不到的問題（安全區域、`vh` 與網址列、鍵盤遮擋、點擊目標、拍照上傳）。這個分支只做研究，不改程式碼。

## 判斷標準

以可檢查的規則為底，v3.7 設計稿是約束，不是改動對象：

- 沒有橫向捲動
- 固定在畫面邊緣的元素不被瀏海、底部橫條、瀏覽器工具列遮住（安全區域）
- 網址列伸縮後，視窗與抽屜的底部不被切掉（`dvh`，不是 `vh`）
- 點擊目標至少 44px
- 輸入框聚焦時頁面不被放大（字級至少 16px）

## 開始前

- 開走查的裝置與瀏覽器要記下來（機型、系統版本、瀏覽器與版本）
- 關閉省電模式
- 網路各跑一次「Wi-Fi」與「行動網路」
- 先用直式；步驟 4、4a、6、7 再各轉橫式看一次
- 要跑在含 2-2 現況確認彈窗（#345，PR #392、#396）的最新 `main`；這個分支本身比較舊，不能直接拿來跑 app

## 走查環境：Android 用 USB 連本機（`adb reverse`）

手機經 USB 直接把自己的 `localhost:5173` 接到電腦的 5173，不用改區網、防火牆或 WSL2 轉發，登入導回網址與 HTTPS 的限制也不會出現。前端的 Vite 會把 `/api` 轉給後端，所以手機只要連 5173 一個埠。資料用本機開發環境（最新 main、假 agent）。

### 一次性準備

1. **手機**：設定 → 關於手機 → 連點「版本號碼」7 次開啟開發人員選項；開發人員選項 → 開啟「USB 偵錯」。
2. **Windows**（不是 WSL）：下載 Android 的 [platform-tools](https://developer.android.com/tools/releases/platform-tools)，解壓縮到例如 `C:\platform-tools`。`adb` 要跑在 Windows 端，因為 USB 裝置接在 Windows 上；WSL2 的 `localhost` 會自動轉給 Windows，所以 Windows 的 `localhost:5173` 就是 WSL2 裡的前端。
3. **電腦**：確認 Windows 的瀏覽器開 `http://localhost:5173` 看得到網站（`make up` 在 WSL 開著）。

### 每次走查

在 **Windows PowerShell**（只有這一步用 PowerShell；專案指令仍在 WSL 跑）：

```powershell
cd C:\platform-tools
.\adb devices
.\adb reverse tcp:5173 tcp:5173
.\adb reverse --list
```

- `adb devices` 第一次會在手機跳出「允許 USB 偵錯？」，按允許；清單要出現裝置且狀態是 `device`（不是 `unauthorized` 或 `offline`）。
- `adb reverse --list` 要看到 `tcp:5173 tcp:5173`。
- 手機的 Chrome 開 `http://localhost:5173`。
- 拔線或手機重開機後 reverse 會消失，要重新執行第二行。

### 在電腦看手機頁面的 F12（選用，建議開）

Windows 的 Chrome 開 `chrome://inspect/#devices`，找到手機上的頁面按 inspect，就能看真實的 console、元素與 `env(safe-area-inset-*)` 的值。走查時遇到版面問題，可以直接在這裡量尺寸。

### 登入

用開發用的測試登入（`DEV_LOGIN_ENABLED=true` 時才有，見 `docs/agents/dev-environment.md`）。不要走 Google 登入：Google 的導回網址不一定允許這個來源。

### 常見問題

| 狀況 | 處理 |
| --- | --- |
| `adb devices` 沒有裝置 | 換一條支援資料傳輸的線（有些線只能充電）；手機 USB 模式選「檔案傳輸」；重開 USB 偵錯 |
| 狀態是 `unauthorized` | 看手機有沒有跳授權視窗；沒有就在開發人員選項按「撤銷 USB 偵錯授權」再重接 |
| 手機開 `localhost:5173` 連不上 | 先確認 Windows 瀏覽器看得到；再執行 `adb reverse --list`；`adb kill-server` 後重來 |
| 頁面開了但 API 失敗 | 確認 `make up` 的 backend 有開；在 WSL 跑 `make doctor` |

### iPhone

USB-C 不能這樣連（Safari 偵錯需要 Mac）。這一輪只用 Android；iPhone 專屬的問題（安全區域、Safari 網址列、輸入框放大）之後另外用區網或 ngrok 補跑步驟 0、3、4、4a、6、7、10，使用 ngrok 前要先經過同意，因為它會把開發環境公開到外網。
