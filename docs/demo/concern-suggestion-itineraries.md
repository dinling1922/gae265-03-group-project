# 推薦的在意事項：demo 與測試日程

用來驗收「依旅遊日程推薦在意事項」（見 GLOSSARY「推薦的在意事項」）。旅遊日程沒有交通分類，所以航班先用 `explore` 分類，搭機資訊寫在標題裡。

驗收方式：在旅遊日程頁用側欄「載入範例日程 ▾」選一份（活動內容見 `frontend/src/features/itinerary/demoItineraries.ts`，出發日依載入當天推算；2-2 固定落在下一個 9/15）、進入 1-2 頁，檢查推薦的前 3 項與理由是否點名對應的活動。LLM 的結果不保證每次相同，「預期」指的是應該進入前 3 名的項目，排序可以不同。

## 1. 主 demo 日程

大阪＋京都，5 天 4 夜（D1–D5）。

**預期前 3 名**：突然生病就醫、信用卡盜刷、不小心弄傷別人或弄壞東西

想觸發的在意事項：
- 突然生病就醫：D1 黑門市場吃生蠔海膽、D3 居酒屋續攤＋深夜拉麵
- 不小心弄傷別人或弄壞東西：D2 租和服、陶藝體驗、電動腳踏車，D4 借用房東的音響和腳踏車
- 信用卡盜刷：D3 心齋橋大採購刷卡、D4 環球影城 App 綁卡
- 班機延誤、行李延誤、行李遺失或損壞：D1、D5 航班與托運行李
