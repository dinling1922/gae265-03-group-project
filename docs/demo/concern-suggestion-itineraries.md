# 推薦的在意事項：demo 與測試日程

用來驗收「依旅遊日程推薦在意事項」（見 GLOSSARY「推薦的在意事項」）。旅遊日程沒有交通分類，所以航班先用 `explore` 分類，搭機資訊寫在標題裡。

驗收方式：建立比較紀錄、照表新增日程活動、進入 1-2 頁，檢查推薦的前 3 項與理由是否點名對應的活動。LLM 的結果不保證每次相同，「預期」指的是應該進入前 3 名的項目，排序可以不同。

## 2. 個別測試日程

每份日程都是獨立的比較紀錄，用來驗證該項在意事項能被推出來。日程只有 2–3 筆活動，其餘名次會由「一般出國風險」補滿（有搭機的話通常是班機延誤）。

**預期前 3 名包含**：需要緊急送醫或家屬趕來

|---|---|---|---|

| D2 | 09:00 | explore | 保津川泛舟 |
