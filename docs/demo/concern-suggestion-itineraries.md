# 推薦的在意事項：demo 與測試日程

用來驗收「依旅遊日程推薦在意事項」（見 GLOSSARY「推薦的在意事項」）。旅遊日程沒有交通分類，所以航班先用 `explore` 分類，搭機資訊寫在標題裡。

驗收方式：在旅遊日程頁用側欄「載入範例日程 ▾」選一份（活動內容見 `frontend/src/features/itinerary/demoItineraries.ts`，出發日是寫死的固定日期：主 demo 2026-07-05、2-2 2026-09-15、其餘 2026-12-10）、進入 1-2 頁，檢查推薦的前 3 項與理由是否點名對應的活動。LLM 的結果不保證每次相同，「預期」指的是應該進入前 3 名的項目，排序可以不同。

## 1. 主 demo 日程

東京 7 天（D1–D7，7/5 日～7/11 六的行程），18 個活動，都有座標可顯示在地圖上：新宿住宿、串燒與市場美食、晴空塔、東京鐵塔、河口湖・富士山一日遊（已付團費）、teamLab Planets 與 SHIBUYA SKY（皆已購票）、淺草與上野、新宿御苑，首尾是成田機場進出（D1 13:00 抵達、D7 14:00 起飛）。

**預期前 3 名**：未調校。這份日程是一般觀光行程，沒有刻意放進特定在意事項的情境（舊的大阪＋京都版本才有），推薦結果以實際跑出來為準。
